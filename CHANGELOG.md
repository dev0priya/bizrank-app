# Changelog

## [1.0.0] - 2026-07-24
### Added
- Complete end-to-end Business Discovery workflow.
- Apify integration for Google Maps Places extraction.
- Automatic deduplication and conflict resolution in PostgreSQL.
- Server-side background jobs with frontend polling support.
- Initial CRM pipelines (Clients and Pipeline Kanban view).
- Client-side rapid CSV export functionality.
- AI Scoring and Opportunity Scoring proxy logic.

### Fixed
- Next.js Vercel 404 deployment error by removing legacy Node.js routing Overrides (`vercel.json`).
- Memory leaks and invalid formats in previous versions of the CSV export logic.
