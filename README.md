# BizRank v1.0

BizRank is a scalable Business Discovery MVP and CRM foundation designed to fetch, deduplicate, and analyze Google Maps businesses dynamically using Apify.

## Core Features
- **Business Discovery Module:** Collects and analyzes real-world businesses via automated background jobs.
- **Dynamic Workflows:** Geolocation targeting (Country > State > City > Area).
- **Automated AI & Opportunity Scoring:** Grades business digital footprint on-the-fly.
- **Robust Deduplication:** Protects the database against duplicate inserts.
- **CSV Export:** Rapid bulk data extraction.
- **CRM Foundation:** Initial pipelines and client dashboards.

## Technologies Used
- Next.js (App Router)
- React
- Prisma (PostgreSQL / Neon)
- Tailwind CSS
- Apify Google Maps Scraper API

# About BizRank

BizRank is a modern AI-powered Business Discovery platform that helps users discover real businesses from Google Maps using highly targeted location-based searches.

Instead of relying on static business directories, BizRank collects live business information through the Google Maps Scraper, processes it using a modern backend, stores it securely in a cloud PostgreSQL database, and presents it inside a professional SaaS dashboard.

The platform is designed for:

- Digital Marketing Agencies
- Website Development Agencies
- Sales Teams
- Freelancers
- Lead Generation Companies
- Local Business Consultants
