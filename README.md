# BizRank v1.0

BizRank is a scalable Business Discovery MVP and CRM foundation designed to fetch, deduplicate, and analyze Google Maps businesses dynamically using Apify.

## Core Features
- **Business Discovery Module:** Collects and analyzes real-world businesses via automated background jobs.
- **Dynamic Workflows:** Geolocation targeting (Country > State > City > Area).
- **Automated AI & Opportunity Scoring:** Grades business digital footprint on-the-fly.
- **Robust Deduplication:** Protects the database against duplicate inserts.
- **CSV Export:** Rapid bulk data extraction.
- **CRM Foundation:** Initial pipelines and client dashboards.

## Technologies Used
- Next.js (App Router)
- React
- Prisma (PostgreSQL / Neon)
- Tailwind CSS
- Apify Google Maps Scraper API
