# Contributing to BizRank

## Project Setup
1. Fork and clone the repository.
2. Run `npm install` to install dependencies.
3. Use `npm run dev` for local development.

## Coding Standards
- Use TypeScript for all new files.
- Favor Server Components where possible for performance.
- Follow the established vanilla CSS token architecture in `globals.css`.
- Keep components modular (One Component = One Responsibility).

## Branch Naming
- `feat/feature-name` for new features
- `fix/bug-name` for bug fixes
- `chore/task-name` for maintenance

## Commit Messages
Use conventional commits (e.g., `feat: add dashboard widgets`, `fix: resolve hydration error`).
