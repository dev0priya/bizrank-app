# UI Guidelines

## Principles
- No horizontal scrolling.
- Minimalistic, SaaS-grade aesthetics (similar to Linear).
- Use glassmorphism panels (`.glass-panel`).

## Colors
- **Backgrounds:** Dark mode defaults to deep navy/black. Light mode uses #f8fafc.
- **Accents:** Vibrant blue and emerald green for success states.

## Typography
- Inter or system-ui sans-serif.
- Strong hierarchy (uppercase subtle tracking for section headers).
